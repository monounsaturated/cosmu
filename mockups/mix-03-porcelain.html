Commands

CLI commands available in the engine. Run via pnpm cosmu <command>

gate run <spec>
Run the full Gate pipeline on a strategy spec. Produces DSR, PBO, max-DD and OOS scores.
paper start <spec>
Begin a paper track for a gate-passed strategy using live market data with no capital at risk.
live arm <spec>
Deploy capital to a strategy. Requires paper track ≥ 30 days and explicit operator confirmation.
live disarm <spec>
Liquidate all positions for a strategy and return funds to the free pool.
data fetch
Pull and backfill all configured data sources to the current timestamp.
data status
Show coverage report for all data feeds (staleness, gaps, last tick).
strategy kill <id> <reason>
Mark a strategy as killed with a recorded reason. Stops paper tracks and blocks re-entry.
