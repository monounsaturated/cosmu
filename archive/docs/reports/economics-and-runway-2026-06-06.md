## When does it make money? (honest)
**It's pre-revenue R&D.** Revenue requires ALL of: (1) an edge EXISTS in markets/data we can access → (2) survives the
honest Gate → (3) survives a 30-day forward-test → (4) survives live with real costs/slippage. Each is a real filter;
the Gate is DESIGNED to kill most candidates (7 theses already failed — though on a broken harness, so TBD after re-run).
- **Earliest real P&L: ~1–2 months** IF the harness re-run surfaces a survivor soon AND it clears forward-test. **Not
  guaranteed** — the honest answer is the Gate may find nothing tradeable in the current universe, in which case "profit"
  needs more search (features/markets/the social hoard). Most quant edge-searches fail; the rare ones compound.
- The asset built so far is **the search machine + the data**, not revenue. That's the correct stage.

## How much real capital? (the math, once an edge is PROVEN)
- **Validate tiny:** $100–1,000 (interlocks default to a $100 budget) → confirm the LIVE track matches the forward-test
  (variance-attribution: does live ≈ sim, net of real fees?). Never skip this.
- **Break-even on running costs (~$3k/yr):** at a proven ~10–20% net annual return (optimistic-but-plausible for a real
  crypto edge), needs **~$15–30k** capital.
- **Meaningful income:** **$50–100k+** at a proven edge → ~$5–20k/yr. Salary-replacement needs $100k–500k+ at a strong,
  durable edge — a big IF.
- Capital is deployed in **Phase 3 (after forward-test), scaled gradually** as the live track confirms.

## The spend discipline (be smart)
- **The trigger to invest CAPITAL is a forward-test survivor — NOT optimism.** Until then, invest in the SEARCH
  (compute/data/dev), kept LEAN. Don't conflate "optimistic about the edge" with "fund it."
- Current spend (~$130–255/mo) is the right level for R&D. $25 Supabase = justified (protect data). Claude 20x =
  justified WHILE actively building + getting throughput (downgrade to 5x in steady-state / cron-only phases).
- **VPS: NO.** A VPS is a box to babysit/patch/scale = the opposite of lean. The lean-but-powerful pipeline already
  exists: Railway (engine+cron, push=deploy) + Vercel (web) + Supabase Pro (data lake) + Modal (elastic heavy compute,
  scale-to-zero) + local Mac (orchestration) + cloud Claude agents (parallel dev). More compute = Modal, not a VPS.

## The one milestone that changes everything
**ONE strategy survives the honest Gate + a 30-day forward-test.** Before it: everything is search (stay lean).
After it: deploy capital gradually + scale. That milestone — not a calendar date — is when the business starts to make money.
