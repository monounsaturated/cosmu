# Roadmap

## Phase 1: Agentic Foundation

- Add repo memory docs and external repo reference workflow.
- Add mode shell: Light, Research, Pro.
- Add agent observability through `agent_steps`.
- Keep Cosmu Light behavior unchanged.
- Add Research v1 experiment creation from natural language.

## Phase 2: Research Lab

- Add data-source registry.
- Add paper candidates and paper bot runs.
- Add Python job runner for isolated backtests and ML tasks.
- Add skeptic reports for leakage, overfit, multiple testing, and unrealistic execution assumptions.

## Phase 3: Broader Data + Paper Venues

- Add web/news/market data sources.
- Add weather, astro, custom API, and CSV source shells.
- Add TradingView script ingestion/backtest path.
- Add IBKR and Polymarket as data/paper adapters.

## Phase 4: Cosmu Pro V1

- Add opt-in Pro pipeline with multi-agent research, bear review, trader, risk reviewer, deterministic validator, execution, and guardian.
- Require live approval by default.
- Add promotion thresholds and approval inbox.

## Phase 5: Controlled Autonomy

- Add capped auto-live setting.
- Add scheduled autonomous research.
- Add memory-driven prompt/strategy improvement.
- Add post-trade self-review and auto-downgrade rules.
